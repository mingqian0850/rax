2 Related Work Language Models for Robot Control. A substantial body of work uses pretrained language models as high-level planners or program
generators for robots. SayCan grounds language-model plans in learned
affordances ( Ahn et al., 2022 ) , Inner Monologue folds environment feedback into iterative
replanning ( Huang et al., 2022 ) , and Code as Policies, ProgPrompt, and VoxPoser synthesize
executable programs, situated task plans, or 3D value maps directly from
instructions ( Liang et al., 2023 ; Singh et al., 2022 ; Huang et al., 2023 ) . These methods
typically invoke the model zero-shot or with a few in-context examples, producing a plan or a
program that is executed with little opportunity to improve from experience. RAX instead treats the language model as a learner : it interacts with the robot over many
episodes and revises its perception and control programs according to what it observes. Agentic Robot Learning. More recently, several works let coding agents improve robot behavior through interaction.
ENPIRE runs agents in a closed loop of automatic reset, rollout, and policy training on a
fleet of bimanual arms, and accelerates discovery by scaling the fleet ( Xiao et al., 2026 ) ;
FAEA and Encore refine policy programs from execution feedback, the latter starting from a few
teleoperated demonstrations ( Tsui et al., 2026 ; Kang et al., 2026 ) ; Baton explores long-horizon
tasks subtask by subtask with transition-aware memory ( Xu et al., 2026 ) ; SimEX develops robot
skills in a simulator reconstructed from the physical workspace before a few trials on the
real robot ( Hu et al., 2026 ) ; RPG practices in simulation on tasks derived from an offline
trajectory dataset and refines a library of reusable skills ( Wang et al., 2026d ) ; EmbodiedSWE
turns coding-agent solutions into training data for vision-language-action
models ( You et al., 2026 ) ; and CaP-X benchmarks coding agents on
manipulation ( Fu et al., 2026 ) . These works establish that agents can improve robot behavior
through interaction, and have so far demonstrated it mainly in tabletop manipulation with
parallel-jaw
grippers ( Xiao et al., 2026 ; Tsui et al., 2026 ; Kang et al., 2026 ; Xu et al., 2026 ; Hu et al., 2026 ; Wang et al., 2026d ) ,
often on a single platform ( Xiao et al., 2026 ; Hu et al., 2026 ; Wang et al., 2026d ) , with humanoid and
mobile settings explored through pretrained locomotion ( You et al., 2026 ) or short
pick-up tasks ( Fu et al., 2026 ) . Several also draw on demonstrations ( Kang et al., 2026 ) ,
offline datasets ( Wang et al., 2026d ) , reconstructed simulators ( Hu et al., 2026 ) , or neural
policy training ( Xiao et al., 2026 ) . RAX complements these efforts: it learns each
task on the robot itself, from its own exploration, and does so across single-arm and bimanual
manipulators, dexterous hands, mobile manipulators performing long-horizon household
activities, and legged humanoids whose locomotion the agent constructs itself, on established
benchmarks and on real robots. On this basis, it studies systematically how performance scales
with exploration, with 3D perception, and with accumulated memory. Scaling Robot Learning. Vision-language-action models ( Brohan et al., 2023 ; Kim et al., 2024 ; Black et al., 2024 ) and imitation
learning methods ( Zhao et al., 2023 ; Chi et al., 2025 ) improve robot capability by scaling
demonstration data and model size, and world action models extend this recipe by learning to
predict how the scene evolves together with the actions that produce
it ( Wang et al., 2026e ; Yuan et al., 2026 ; Kim et al., 2026 ; Bi et al., 2026 ) . To cover multiple embodiments, generalist
policies pool demonstrations across robots into a single training
mixture ( O’Neill et al., 2024 ; Team et al., 2024 ; Doshi et al., 2024 ; Intelligence et al., 2025 ; Bjorck et al., 2025 ) ,
and a robot outside this mixture requires data of its own and further fine-tuning. In language
modeling, computation spent at inference has emerged as a further scaling
axis ( Guo et al., 2025 ; OpenAI, 2024 ) . RAX instead studies how robot
capability grows with online experience acquired and organized by the agent itself, without
additional demonstrations or parameter updates. Because this experience is gathered on the
robot at hand, RAX extends to a new embodiment without pooled data, and adapts to it within a
few episodes of exploration. Memory and Cognitive Architectures. Language agents can retain experience as explicit memory: Voyager grows a library of code
skills through open-ended exploration in a game ( Wang et al., 2023 ) , and Reflexion and
ExpeL distill feedback into textual lessons that improve later
attempts ( Shinn et al., 2023 ; Zhao et al., 2024 ) . At a broader level, classical cognitive
architectures such as Soar and ACT-R structure intelligent behavior around perception,
memory, and deliberation ( Laird et al., 1987 ; Anderson et al., 2004 ) , CoALA revisits this structure
for language agents ( Sumers et al., 2023 ) , and Sutton’s common model of the intelligent
agent ( Sutton, 2022 ) and OaK architecture ( Sutton et al., 2022 ) hold that all
task-specific knowledge should be acquired at runtime from the agent’s own experience, a view
developed further as the era of experience ( Silver and Sutton, ) . RAX brings this
view to physical robots, where every skill is executable control code that enters memory only
after it succeeds without supervision.
